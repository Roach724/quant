## 教训

- Futu OpenD 需要 **行情登录 (qot_logined)**，只连上不够
- `--source futu_stock --all` 混入港股，需加 `--market us` 过滤
- Futu API 实际延迟 ~8s/请求（GCP→Futu 服务器网络往返），比预估慢很多
- 速率限制 60次/30秒 不是瓶颈，网络延迟才是
